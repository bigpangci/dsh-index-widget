# dsh-index-widget

一个挂在 DeepSeek Harness 标题栏上的 A 股行情插件：平时是一条安静的滚动胶囊，想细看就点开，想摸鱼就放弹幕。

> 写这个插件的原因很朴素：想知道上证有没有跌破三千七，但又不想为此多开一个浏览器标签页。

## 它长什么样

**胶囊**（默认形态）：会话标题栏里 220px 宽的一条，左侧一个状态点，右边滚着「上证 3693.47 +0.20% 深证 11556.43 +1.95% …」，鼠标悬停会停下来让你看清。

**弹窗**（点胶囊）：涨跌家数、两市成交额，加四段行情表——大盘指数、贵金属、自选股、自选板块。

**弹幕**（可选）：勾选的品种会横着或竖着从整个窗口飘过去，鼠标穿透、点不到、不挡操作。给开会时偷瞄一眼用的。

## 功能

| 功能 | 说明 |
| --- | --- |
| 顶部跑马灯 | 宽度 120–520px 可调，悬停暂停，系统开了「减少动态效果」时自动停 |
| 行情弹窗 | 涨跌家数、成交额、四段行情表，红涨绿跌，等宽数字对齐 |
| 四类内容 | 8 个大盘指数、4 个贵金属（沪金 / COMEX 黄金 / 沪银 / 黄金 ETF）、自选股（上限 12 只）、26 个行业板块 |
| 弹幕模式 | 字号、速度、密度、不透明度、方向、字体、字重、气泡底、突变脉冲，九项都能调 |
| 交易时段感知 | 盘中每 5 秒刷新，收盘后每分钟；状态点显示交易中 / 集合竞价 / 午休 / 收盘 |
| 主题跟随 | 深色浅色两套配色，跟随 Harness 主题，切换即时生效 |
| 无需 API Key | 直接读东财公开接口，浏览器同源直连 |

## 安装

需要 DeepSeek Harness（桌面版或 `dsh web`）。这是本地 bundle，不上 npm，两种装法任选。

**A. 交给 Harness 里的 Agent（推荐）**

让它用 `plugin_manager` 的 `install_bundle` 把这个目录装成 bundle，`target` 传目录的绝对路径。装完刷新页面。

**B. 手动挂到 profile**

1. 把仓库放到任意目录，例如 `C:\plugins\dsh-index-widget`。
2. 打开 profile 的 `package.json`（桌面版在 `%USERPROFILE%\.dsh\profiles\desktop\package.json`），两处各加一行：

   ```json
   "dependencies": {
     "dsh-index-widget": "link:C:/plugins/dsh-index-widget"
   },
   "dsh": {
     "profile": {
       "bundles": ["...", "dsh-index-widget"]
     }
   }
   ```

3. 重启 Harness，然后 `Ctrl+R` 刷新页面。标题栏出现胶囊就算成功；没出现就打开弹窗看报错，一般是无中生有的拼写问题。

## 使用

- **点胶囊**：打开弹窗。
- **选择内容**：勾选要显示的指数、贵金属、板块；自选股在这一页输入 6 位代码添加，点标签移除。改动即时生效，不用点保存。
- **设置**：胶囊宽度，以及下半部分的弹幕九件套（见下）。
- **Esc**：弹窗里按一下回行情页，再按一下关窗。
- 所有选择存在浏览器 `localStorage`，换设备不跟随——从某种意义上说，这是你在这台机器上的私人看盘习惯。

## 弹幕设置一览

| 项 | 范围 / 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 开关 | 开 / 关 | 关 | 弹窗页脚也能一键切 |
| 字号 | 10–26px | 15 | 每条再有 ±10% 的随机 |
| 速度 | 8–45 秒 / 屏 | 24 | 数字越小飘得越快 |
| 密度 | 0.4×–2.5× | 1× | 每 1.6 秒出几条 |
| 不透明度 | 15%–90% | 50% | 太高会抢正文的戏 |
| 方向 | 右→左 / 左→右 / 上→下 / 下→上 / 随机 | 右→左 | 竖向按 150px 一列分通道 |
| 字体 | 等宽 / 黑体 / 衬线 / 楷体 | 等宽 | 楷体在 Windows 上是自带的 KaiTi |
| 字重 | 常规 / 加粗 | 常规 | 字号小的时候加粗更清楚 |
| 气泡底 | 无 / 有 | 无 | 有气泡时左侧带一条涨跌色竖条，像行情软件的标签 |
| 突变脉冲 | 开 / 关 | 开 | 两次刷新间涨跌幅跳 ≥0.5% 的品种，飘过时放大 3px、拉满亮度、带光晕，持续 15 秒 |

几条为了「不碍事」做的约束，写在代码里也写在这里：

- 整层 `pointer-events: none`，鼠标怎么点都点不到。
- 位移走 `translate3d`，交给合成器，不触发布局。
- 同时在屏条数封顶 18，超了丢最旧的；标签页在后台时不生成新条目。
- 弹窗打开时弹幕定格原地（关掉继续，不从头重来）。
- 轨道避开顶部 56px 和底部输入框区域，不会被切一半。

## 结构

```
index.js          宿主半：空实现，只为满足 bundle 结构
client.js         浏览器半：全部界面与取数逻辑
cordis.patch.yml  bundle 补丁，插入本插件
locale/           插件列表里的标题与描述
icon.svg          图标
```

没有宿主路由。东财接口会把请求的 `Origin` 原样回填进 `Access-Control-Allow-Origin`，页面可以直接 `fetch`，所以宿主半只剩一个空壳——这也意味着插件的全部逻辑都在 `client.js` 一个文件里，改起来很省心。

## 常见问题

**为什么板块只有 26 个，不能自动拉全？**
拉板块清单的接口（`clist`）在这个环境里会被上游直接断开连接，加 `ut`、加 `Referer` 都不行。所以清单是内置的，写死在 `BOARDS` 里，想加自己改数组。

**弹幕会不会拖慢界面？**
不会，除非你同时开十几个别的动画。条数有上限，位移走合成器，后台标签页不生成新条目。真觉得卡，把密度调到 0.4× 就基本无感了。

**某条弹幕突然变亮变大是 bug 吗？**
不是，是突变脉冲：它在这两个刷新周期之间跳了 0.5 个点以上，值得你抬头看一眼。不想看就在设置里关掉。

**行情和券商对不上？**
以券商为准。这个插件只做「大概知道今天怎么样」，不做交易参考。

**怎么彻底关掉？**
设置里把弹幕关掉、把胶囊宽度调到最小只是让它不碍眼；要完全移除，把 `dsh-index-widget` 从 profile 的 `bundles` 和 `dependencies` 里删掉，重启。

## 开发

```sh
node --check client.js
```

只有浏览器半，改完不用重启应用，但需要让 Harness 重建模块图：`plugin_manager` 里把 bundle 设成 false 再设成 true，然后 `Ctrl+R`。宿主半改了才需要重启。

## 数据来源

行情来自东方财富公开接口（`push2.eastmoney.com`），没有 Key、没有账号、没有后端。接口随时可能变，取数失败时胶囊会显示「行情不可用」并自动重试，不会把错误弹到你脸上。
